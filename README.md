# Personal Portfolio

A responsive personal portfolio for **Cesar Francisco** built with HTML, CSS, Bootstrap 5, and vanilla JavaScript.

## Features
- Responsive sticky navigation (collapsible on mobile)
- Hero section with an animated typewriter introduction
- About, Skills, Projects, Certificates, and Contact sections
- Working certificate carousel with clickable thumbnails
- Responsive project and skills tiles
- Accessible controls (keyboard navigation, ARIA labels, skip link)
- Respects `prefers-reduced-motion`

## Technologies
- HTML5, CSS3
- Bootstrap 5.3 (CSS + JS bundle)
- Font Awesome 5
- Vanilla JavaScript (no jQuery)
