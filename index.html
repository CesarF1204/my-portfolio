Professional Skills

A timeline of the core professional skills I've developed and the experience behind each one.

HTML

I started working with HTML in 2016, initially learning the fundamentals of structuring web pages. Since then, I've used semantic HTML to build the foundation of responsive and accessible web interfaces across my projects.

CSS

I've worked with CSS since I started learning web development, progressing from basic styling to building responsive layouts with Flexbox and Grid. I use CSS to turn structured pages into clean, practical interfaces and continue refining my approach through hands-on projects.

PHP

I've used PHP to build dynamic, database-driven web applications, including handling forms, sessions, CRUD operations, and backend logic. My experience ranges from foundational PHP development to intermediate-level application work, particularly in projects that require server-side processing and database integration.

Laravel

I've used Laravel to structure and develop PHP-based web applications, working with its conventions to organize backend logic and application features. My experience with Laravel comes from building practical, database-driven systems rather than using the framework only for isolated exercises.

JavaScript

JavaScript has been a major part of my development experience, from building interactive frontend features to supporting backend applications with Node.js. I've used it extensively in production work and personal projects to create dynamic, responsive

ReactJS

I've used ReactJS to build interactive, component-based user interfaces and develop frontend features for web applications. Working with React has strengthened my understanding of reusable components, state management, API integration, and building interfaces that respond smoothly to user interactions.

NodeJS

I've used NodeJS to build server-side applications and backend functionality using JavaScript. My experience includes working with application logic, APIs, data processing, and connecting backend services with databases and frontend applications.

ExpressJS

I've worked with ExpressJS alongside NodeJS to create backend routes and RESTful APIs. It has given me practical experience structuring server-side applications and handling requests, responses, and communication between different parts of a system.

MySQL

I've worked with MySQL extensively in developing database-driven web applications, handling structured data, relationships, queries, and CRUD operations. I’ve used it with PHP and Laravel to support systems involving records, reservations, reports, and other application workflows.

MongoDB

I've worked with MongoDB for applications that use a flexible, document-based approach to data management. My experience includes integrating MongoDB with web applications and working with application data where a NoSQL structure is appropriate.

Git and GitHub

I use Git and GitHub to manage, version, and organize my code throughout the development process. I rely on them to track changes, maintain project history, collaborate when needed, and keep my professional and personal projects structured and accessible.

Web Scraping

I've worked with web scraping using WebQL to extract, organize, and process information from websites for practical data-driven applications. I've also maintained scraping scripts and scheduled jobs to automate recurring data collection, monitor the process, and troubleshoot issues when website structures or data sources change.
